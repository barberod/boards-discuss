# Changelog

All notable changes to Boards Discuss are documented here.

## 0.1.0

- Added an Activity Bar panel for Azure Boards work-item search and discussion reading.
- Added assignment, state, type, text, ID, and sorting controls.
- Added descriptions, acceptance criteria, rich replies, safe external links, and author-owned comment deletion.
- Added Azure DevOps identity lookup and real @mention markup.
- Added favorite and pin persistence plus configurable mention notifications.
- Added secure PAT storage, guided setup, tests, and Marketplace documentation.
